# Lista de comprobación del examen

- [x] RF-01: catálogo desde HTTP con imagen, nombre, estado y especie.
- [x] RF-02: detalle con imagen, nombre, estado y al menos tres datos adicionales; navegación de regreso del sistema.
- [x] RF-03: búsqueda parcial local, sin distinguir mayúsculas/minúsculas; aviso de alcance.
- [x] RF-04: paginación real, número actual y botones bloqueados en límites.
- [x] RF-05: agregar/quitar favoritos, pantalla de favoritos y persistencia de IDs con SharedPreferences.
- [x] RF-06: carga, errores comprensibles, resultados vacíos y reintento.
- [x] RT-01: modelo Dart `Character.fromJson`, campos opcionales protegidos y peticiones HTTPS.
- [x] RT-02: separación entre modelos, servicio, estado, pantallas y widgets; imágenes remotas con fallback.

Antes de presentar:
1. Ejecuta `flutter pub get`.
2. Ejecuta `flutter analyze` y corrige cualquier advertencia que aparezca con tu versión instalada de Flutter.
3. Prueba el catálogo, búsqueda, paginación, detalle, favoritos y el cierre/reapertura de la app.
4. Completa los nombres de integrantes y contribuciones en README.md.
5. Sube el proyecto a GitHub y agrega el enlace solicitado por el docente.
